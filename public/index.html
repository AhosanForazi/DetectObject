DetectObject

Real-time object detection, multi-object tracking (ByteTrack), virtual line counting, and browser live webcam powered by YOLO11n and Streamlit.

Core System Features

Image Detection

Upload JPG, PNG, or WEBP images or select built-in sample images to detect and classify 80 COCO objects with confidence thresholds.

Video Detection

Frame-by-frame processing of MP4, AVI, MOV, or WEBM clips with PyAV H.264 browser-compatible video re-encoding.

Live Webcam

Browser camera snapshot capture and client-side getUserMedia streaming with live bounding box overlays.

Object Tracking & Counting

Persistent tracking IDs via ByteTrack and BoT-SORT, motion trajectory trails, bidirectional counting lines, and ROI zone counters.

Model Information

Weights inspection, CPU/CUDA hardware detection, measured test split metrics, and precision-recall evaluation curves.

Cloud & Docker Ready

Fully containerized with production Dockerfile, Render Blueprint spec, and multi-platform compatibility.
